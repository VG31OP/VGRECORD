# Contribution Guidelines

Thank you for considering contributing to VGRECORD!

## How to Contribute

1. **Fork the Repository**
   - Click the "Fork" button on https://github.com/VG31OP/VGRECORD

2. **Clone Your Fork**
   ```bash
   git clone https://github.com/your-username/VGRECORD.git
   cd VGRECORD
   ```

3. **Create a Feature Branch**
   ```bash
   git checkout -b feature/your-feature-name
   ```

4. **Make and Test Changes**
   ```bash
   npm install
   npm run dev
   npm run typecheck
   ```

5. **Commit and Push**
   ```bash
   git add .
   git commit -m "feat: description of your improvement"
   git push origin feature/your-feature-name
   ```

6. **Open a Pull Request**
   - Open a pull request against the `main` branch of https://github.com/VG31OP/VGRECORD
